# Paint Store

A responsive color-guide storefront page built as part of Codecademy's web development curriculum.

## Project origin

<a href="https://www.codecademy.com/">
  <img src="https://raw.githubusercontent.com/matwal42083/myPortfolio/main/src/assets/images/CodecademyLogo.png" alt="Codecademy logo" width="220">
</a>

This project is based on Codecademy's Paint Store assignment and its supplied reference materials. The assignment guided the page, though the materials were not a conventional wireframe.

## Features

- Responsive desktop and mobile layouts
- HSL color swatches for red, green, and blue palettes
- Semantic HTML and CSS media queries

## Built With

- HTML5
- CSS3

## Viewing Locally

Open `index.html` in a browser.
